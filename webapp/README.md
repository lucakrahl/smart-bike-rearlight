# webapp/

Progressive Web App (PWA) mit Web Bluetooth API — die **Rechen- und Datsenke**
(Bible Kap. 7). Empfängt das versionierte Telemetrie-Frame (FR-TEL-06),
berechnet Statistik/Sensorfusion (Bible Kap. 2.3), speichert die Fahrt (CON-01)
und visualisiert die MVP-Kennzahlen (Bible Kap. 2.4). Verbindung ist
unidirektional (ESP32 → App, FR-SYS-04). _Noch nicht begonnen._
